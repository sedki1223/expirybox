# ExpiryBox

ExpiryBox is a Flutter mobile application designed to help users keep track of items and their expiration dates.

The project was built as a practical mobile development project using Flutter and local device storage.

## Tech Stack

* Flutter
* Dart
* SharedPreferences

## Features

* Manage items with expiration information
* Store data locally on the device
* Simple mobile interface for quickly checking saved items

## Getting Started

### Prerequisites

Make sure you have Flutter installed and configured on your machine.

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd expirybox
```

Install the dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## Storage

ExpiryBox uses `SharedPreferences` for local data persistence, allowing saved information to remain available between application sessions without requiring a backend service.

## Project Purpose

This project was created to practice Flutter and Dart development, mobile application structure, local data persistence, and building a complete functional application from start to finish.
